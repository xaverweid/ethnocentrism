# ethnocentrism
This repository serves as 2024 autumn Complexity Science (7205RM46XY, University of Amsterdam) group project repository on ethnocentrism.

## Group Members

Afon Khari, Xaver Weidinger, Yifan Luo

## Model Description

This repository contains a Network Agent-Based Model (ABM) designed to simulate the co-evolution of strategies and social structures in the classical Prisoner’s Dilemma (PD) game.

Specifically, this project explores how group markers and social network dynamics lead to the emergence and stabilization of ethnocentrism—the tendency to cooperate with in-group members while defecting against out-group members.
Key Concepts & Definitions

In the context of this research, Ethnocentrism is defined by behavioral rules based on group identity within the Prisoner's Dilemma game:

    Cooperate ("C") with in-group agents.

    Defect ("D") with out-group agents.

Emergent Agent Types

Through evolutionary pressures and network interactions, agents naturally differentiate into four distinct behavioral archetypes:

    Altruist: Cooperates with both in-group and out-group members.

    Ethnocentrist: Cooperates with in-group members; defects against out-group members.

    Cosmopolitan: Defects against in-group members; cooperates with out-group members.

    Egoist: Defects against both in-group and out-group members.

Model Features

    Network-Based Interactions: PD-game interactions are constrained and shaped by an underlying social network topology.

    Group-Membership Barriers: Social barriers and tags influence interactions and tie-formation based on group affiliation.

    Co-Evolutionary Dynamics: Simultaneous co-evolution of agent strategies in the PD game and the structure of the social network itself.

    Emergent Behavior: Tracks how macro-level social phenomena (like ethnocentric clusters) emerge from micro-level behavioral rules.
